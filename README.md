💻 Code Runner

🚀 A simple, fast and beginner-friendly online code runner for writing, executing and testing code directly in your browser.

Inspired by modern online compiler platforms, this project provides a clean interface where users can select a programming language, write their code, run it and instantly see the output. ✨

🌐 Supported Languages

🐍 Python — Write and run Python programs
🌐 HTML — Create and preview web pages
🎨 CSS — Style your HTML projects
⚡ JavaScript — Write and execute JavaScript code

«More programming languages can be added in future updates. 🚀»

✨ Features

- 📝 Easy-to-use code editor
- ▶️ Run code instantly
- 📤 Separate output section
- 🔄 Clear/Reset code option
- 🔀 Switch between programming languages
- 📱 Mobile-friendly interface
- 💻 Desktop-friendly design
- 🎨 Clean and modern UI
- ⚡ Fast and simple experience
- 🐛 Easy-to-understand error output
- 📋 Copy code/output easily
- 🌙 Dark/Light mode support (if enabled)

🎯 Goal

The main goal of this project is to create a simple online coding platform for students and beginners where they can practice programming without installing a compiler or setting up a development environment.

🚀 How It Works

1. 🌐 Open the website
2. 🔀 Select your programming language
3. 📝 Write your code
4. ▶️ Click Run
5. 📤 View the output
6. 🔄 Edit and run your code again
